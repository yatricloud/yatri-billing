# LLM Guidelines

When working in this repository:
1. **Context First:** Always read `AGENT.md` and `MEMORY.md` to understand the current architecture constraints, especially regarding Flutter Web SQLite implementation.
2. **Minimal Changes:** When editing HTML/JS for the web bootloader, preserve the minimal design requested by the user.
3. **Paths:** Pay close attention to the difference between `web/` (source) and `build/web/` (compiled output).
